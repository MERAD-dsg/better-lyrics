# Better Lyrics — установка (сборка с «Чистым полноэкранным режимом»)

Версия: 3.0.2.2

## Прямые ссылки для скачивания

- Chrome / Edge / Brave / Opera:
  <https://github.com/MERAD-dsg/better-lyrics/raw/arena/5257e29b-better-lyrics/release/better-lyrics-3.0.2.2-chrome.zip>
- Firefox:
  <https://github.com/MERAD-dsg/better-lyrics/raw/arena/5257e29b-better-lyrics/release/better-lyrics-3.0.2.2-firefox.zip>

На странице репозитория: `release` → файл `better-lyrics-3.0.2.2-chrome.zip` → кнопка **Download raw file**.

## Что нового

Новый тумблер **Display → Fullscreen → «Чистый полноэкранный режим»** (по умолчанию включён).
В полноэкранном режиме он убирает:

- футер в конце текста песни: «Источник / …», «Искать на Genius», «Отправить текст»,
  «Отметить неточность», карточка Unison с голосованием, Discord, промо Shaders;
- плавающую панель управления (док) в углу панели текста — источник, перевод, офсет, обновить, PiP;
- кнопки громкости и «⋮» (быстрые действия) справа от названия песни;
- строчку с источником на финальной карточке в режиме караоке.

Выключите тумблер в настройках расширения, если захотите вернуть эти элементы.
В обычном (не полноэкранном) режиме ничего не меняется.

## Chrome / Edge / Brave / Opera (самый простой способ)

1. Распакуйте `better-lyrics-3.0.2.2-chrome.zip` в любую удобную папку
   (или используйте уже распакованную папку `chrome` из этого архива).
2. Откройте в браузере `chrome://extensions` (в Edge — `edge://extensions`, в Brave/Opera — тоже `chrome://extensions`).
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку
   (ту, где лежит `manifest.json`).
5. Откройте [music.youtube.com](https://music.youtube.com) — обновите вкладку, если она уже была открыта.

> Важно: папку, которую вы выбрали, удалять нельзя — браузер читает расширение прямо из неё.

## Firefox

1. Распакуйте `better-lyrics-3.0.2.2-firefox.zip`
   (или используйте уже распакованную папку `firefox`).
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение»** и выберите файл `manifest.json` внутри распакованной папки.
4. Откройте [music.youtube.com](https://music.youtube.com).

> Временные дополнения в Firefox удаляются при закрытии браузера. Для постоянной установки
> используйте официальную подписанную версию из [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/better-lyrics/).

## Если что-то пошло не так

- Изменения вступят в силу сразу; если текст не обновился — обновите страницу YouTube Music.
- Если пустая панель текста или кривая вёрстка — отключите «Чистый полноэкранный режим»
  в настройках и перезагрузите вкладку.
- Логи расширения: настройки → General → Show logs, затем консоль вкладки (F12).
